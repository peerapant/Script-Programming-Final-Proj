### 1. ไฟล์ `README.md` (สำคัญที่สุด)

ไฟล์คู่มือการใช้งานที่ต้องมีอยู่ที่หน้าแรกของ Repository (สร้างไว้ที่โฟลเดอร์หลัก `rockspec-ocr/README.md`):

```markdown
# 🗿 RockSpec OCR
> Automated Geological Thin-Section Image Metadata & Batch Renaming Pipeline

ระบบอ่านสเกลภาพหินและเปลี่ยนชื่อไฟล์อัตโนมัติด้วย Computer Vision (OpenCV) และ EasyOCR พร้อมระบบเฝ้าระวังโฟลเดอร์ (Folder Watcher) และการแจ้งเตือนผ่าน Webhook

---

## 🛠️ การติดตั้งใช้งาน (Installation)

1. **Clone Repository**
   ```bash
   git clone [https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git](https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git)
   cd rockspec-ocr

```

2. **สร้างและเปิดใช้งาน Virtual Environment**
```bash
# macOS / Linux
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate

```


3. **ติดตั้ง Dependencies**
```bash
pip install -r requirements.txt

```



---

## 🚀 วิธีการใช้งาน (Usage)

1. เตรียมไฟล์ข้อมูลหลัก **`Master_Rocks.xlsx`** และวางโฟลเดอร์รูปภาพดิบไว้ใน **`Input_Images/`**
2. รันแอปพลิเคชันหลัก:
```bash
python app.py

```


3. เลือกโหมดการทำงานจากเมนู:
* **1. Dry-Run Mode:** จำลองการจับคู่ชื่อไฟล์โดยยังไม่เปลี่ยนชื่อจริง
* **2. Execute Mode:** เปลี่ยนชื่อไฟล์จริง และบันทึกประวัติลง `process_log.xlsx`
* **3. Folder Watcher Mode:** เปิดระบบเฝ้าระวังโฟลเดอร์ ตรวจจับไฟล์ใหม่แบบ Real-time
